Политика конфиденциальности VoxiProxyTun

Дата вступления в силу: 11 мая 2026 г.

VoxiProxyTun ("Приложение") — это VPN-сервис, разработанный A NETWORK TECHNOLOGIES, TOO ("мы", "наш"). Мы серьёзно относимся к вашей конфиденциальности и стремимся обеспечить максимальную защиту ваших данных.

1. Какие данные мы собираем

  • URL подписки — хранится локально на вашем устройстве для загрузки конфигурации серверов.
  • Идентификатор устройства (HWID) — анонимный хэш, используется для управления подпиской. Не содержит персональных данных.
  • Модель устройства и версия ОС — передаются серверу подписки для корректной работы.

2. Какие данные мы НЕ собираем

  • Мы не ведём логов вашей интернет-активности.
  • Мы не записываем посещённые вами сайты, DNS-запросы или содержимое трафика.
  • Мы не отслеживаем ваше местоположение.
  • Мы не передаём ваши данные третьим лицам.
  • Мы не используем рекламные трекеры или аналитику.

3. Как работает VPN

Приложение создаёт зашифрованный туннель между вашим устройством и VPN-сервером. Весь интернет-трафик проходит через этот туннель, что обеспечивает:

  • Защиту данных в публичных Wi-Fi сетях
  • Шифрование интернет-соединения
  • Приватность при работе в интернете

4. Хранение данных

Все настройки приложения (URL подписки, выбранный сервер, параметры маршрутизации) хранятся только на вашем устройстве в защищённом хранилище iOS/macOS. При удалении приложения все данные удаляются.

5. Сторонние сервисы

Приложение использует:

  • DNS-серверы (1.1.1.1, 8.8.8.8) — для разрешения доменных имён через VPN-туннель.
  • connectivitycheck.gstatic.com — для проверки качества соединения (стандартный сервис Google для проверки подключения).

6. Безопасность

Мы используем современные протоколы шифрования (VLESS, Reality, TLS) для защиты вашего трафика. Конфигурация передаётся в зашифрованном виде.

7. Дети

Приложение не предназначено для детей младше 17 лет и не собирает данные о несовершеннолетних.

8. Изменения политики

Мы можем обновлять данную политику. Актуальная версия всегда доступна на этой странице. При существенных изменениях мы уведомим пользователей через приложение.
